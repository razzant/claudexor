Use the headroom you already pay for.

Add separate accounts for the same agent without mixing credentials. Where the vendor reports quota, for Claude Code, Codex and Antigravity, Claudexor shows each account's live windows and moves an unpinned run off an account that hit a confirmed limit. An ordinary network error never moves it, and a pinned run stays where you put it.

Separate profiles
Each account keeps its own configuration and its own credential store. No shared credential jar.
Real quota facts
The windows a vendor reports, with their resets, stay with the account that reported them: five-hour and seven-day for Claude Code and Codex, per model for Antigravity.
One holder at a time
When a run that already did work moves to the next account, its session moves with it where the agent supports that. Otherwise the work continues from a recorded packet.

Use Claudexor in Hermes, Pi or OpenClaw.

Ask a second model to explain a passage or draft an edit for review. Your agent calls the Claudexor CLI on its machine and brings the answer, or the proposed change, back to the same chat.

First, the CLI

On the machine that runs your agent: macOS or Linux with Node.js 24.15 or newer, and the agent's own CLI installed. The host process must find node and claudexor on its PATH. Use the account you already connected; switching accounts during a Codex sign-in can revoke other sessions. CLI and account setup

$ npm install -g claudexor
# Open the Codex sign-in link
# in a private window.
$ claudexor auth login codex
$ claudexor doctor

Integration by Ouroboros.

No magic session teleportation.

Where rotation applies
Live quota and moving a run off a spent account cover Claude Code, Codex and Antigravity, the agents whose vendors report quota.
Where each agent can take part
Every connected agent can join the same thread wherever Doctor has enabled the requested role. A role that is not available stays off, with the reason attached.
What “shared context” means
Between different agents, bounded continuation packets carry the thread. Between two accounts of the same agent, a session has one holder at a time: it moves with the run where the agent supports that, or the work continues from a recorded packet.
What this page collects
Nothing. No analytics, no trackers, no remote fonts, no external requests of any kind.

Start with the app, or stay in the terminal.

On macOS 26 or newer, download the signed and notarized app and drag it to Applications. It brings its own runtime, so you need no Node or pnpm. In a terminal on macOS or Linux, install the npm package with Node.js 24.15 or newer (use the latest Node 24 release), or build it from source.

Connect one coding agent through Claudexor, choose a project and try an Ask question. A subscription login counts against that plan; an API key is a paid fallback. Git and the selected coding agent are checked during setup.

$ npm install -g claudexor
$ claudexor doctor
# Open the Codex sign-in link
# in a private window.
$ claudexor auth login codex
$ cd /path/to/your/project
$ claudexor ask "map this repo"
$ claudexor inspect <run_id>

No telemetry. Everything runs on your machine, and files are the source of truth. MIT licensed, which means the bugs are yours now too.
