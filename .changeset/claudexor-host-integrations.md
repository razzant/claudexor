Connect Hermes Agent, Pi, and OpenClaw to the local Claudexor MCP server and delegation skill. Install the Hermes plugin by Git commit or load the Pi extension and OpenClaw bundle from a checkout. The `claudexor` npm wrapper now contains Pi package metadata, an extension, its MCP descriptor, and the skill. Publishing the wrapper with these resources and the `pi-package` keyword would make it eligible for Pi's package gallery.
