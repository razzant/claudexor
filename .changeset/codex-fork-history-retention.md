forks located under imported names. Only dated, single-ID session rollouts can
retire. Cleanup counts retained bases and referenced files even when a sole
unreadable file retires. A new reference absent from its inventory defers cleanup for
one pass. A sole unreadable candidate may retire alone if no readable header names
it as a base. Its retirement holds the home and marks the pass truncated only
when it defers another eligible file. Multiple unreadable files or an unreadable
